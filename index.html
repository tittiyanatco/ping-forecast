ฝนพยากรณ์รายวัน (จุดกริด P.1)

ปริมาณฝนรวมรายวันจาก Open-Meteo Forecast API · หน่วย มม.

ความแม่นยำที่ตรวจสอบแล้ว แยกจากพยากรณ์ปัจจุบัน

นับเฉพาะคำพยากรณ์ใน track ปัจจุบันที่มีค่าจริงแล้ว · MAE = ค่าคลาดเคลื่อนสัมบูรณ์เฉลี่ย (m³/s) · n = จำนวนตัวอย่างที่เฉลยแล้ว

ประวัติคำพยากรณ์ที่เฉลยแล้วล่าสุด

คำพยากรณ์ที่ถึงกำหนดแล้วและเทียบกับค่าจริง (ใหม่สุดอยู่ล่าง)

เกี่ยวกับข้อมูล

รายละเอียดโมเดล แหล่งข้อมูล และข้อจำกัด

โมเดลที่แสดง

  • Persistence — ใช้ค่าน้ำท่าล่าสุดคงที่ (Q(t+L) = Q(t)) เป็นเส้นฐานอ้างอิง
  • XGB น้ำท่า (set 1b) — ใช้ค่าน้ำท่าย้อนหลัง 7 วันจาก 4 สถานี (P.1, P.67, P.20, P.75)
  • XGB + ฝน NWP ทดลอง — เพิ่มคุณลักษณะฝนอนาคต ฝึกด้วยค่าเฉลี่ยฝนจากสถานีวัดจริง แต่ตอนใช้งานป้อนฝนพยากรณ์จุดเดียว จึงอาจมี spatial mismatch และยังไม่ใช่ configuration Track B เต็มรูปแบบ

ข้อจำกัดที่ต้องทราบ

  • ค่าจาก endpoint เป็นค่า provisional ต่างจากชุดข้อมูลงานวิจัยที่ P.1 ประมาณ 2–3 m³/s ใช้เพื่อสาธิตและตรวจสอบย้อนหลังเท่านั้น ไม่นำไปฝึกโมเดลใหม่
  • ระบบนี้เป็น ระบบทดลอง ไม่ใช่ระบบเตือนภัยน้ำท่วม และไม่ใช้ผลโมเดลเป็นคำยืนยันการเตือนภัย
  • ยังไม่มีงานสร้างคำพยากรณ์อัตโนมัติรายวัน ความสดของข้อมูลจึงอาจล่าช้าจากรอบที่เผยแพร่

แหล่งข้อมูล: น้ำท่า/ระดับน้ำจากสถานีของกรมชลประทาน (RID ภาค 1) ผ่าน endpoint สาธารณะ · ฝนพยากรณ์จาก Open-Meteo (จุดกริด P.1) · ผลรวมฝนสะสมคำนวณจากฝนพยากรณ์รายวันจริงของรอบนี้ ไม่ได้เติมค่าที่ขาด
